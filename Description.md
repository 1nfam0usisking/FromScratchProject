# Description

This simple application makes a family Grocery and meal list.

## Overview

The grocery and meal list allows family members to suggest meals and vote on preference.  once voting is done a grocery list is generated.  a family member can then check thing off the list.

## Functions

### Add meal Suggestions

This funtion allows family members to suggest meals to be seen by the rest of the family  

### Vote on meals

This function allowes users to vote on the meals they find the tastiest (to avoid tiest), and determines the winner. 

### generate shopping list

Once voting is complete, a shoping list will be generated with all necisary ingredients for the selected meal. 

## Design

### Meal Interface

There will be a text box for the meal name as well as necisary ingredient with a green submit button. Once the submit button has been pressed the user will be notified that there submition is up for voting. 

### Voting Interface

There will be a list of all the suggested meals with a button next to them. The user will get to pick their favorite two meals, and vote on them. When voting is compleate a display will indicate the winner. 

### Shoping List UI

After the winner has been declared a yellow shoping list will appear with all necisary ingredients.
