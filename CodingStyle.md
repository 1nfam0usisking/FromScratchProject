## Naming Conventions

| type          | Convention     | Example                          |
|---------------|----------------|----------------------------------|
| Variables     | `snake_case`   | `meal_name`, `vote_count`, `is_collected` |
| Functions     | `snake_case`   | `add_meal()`, `cast_vote()`, `get_winner()` |
| Classes       | `PascalCase`   | `Meal`, `VotingManager`, `ShoppingList` |
| File names    | `snake_case.py`| `meal.py`, `voting_manager.py`, `shopping_list.py` |
